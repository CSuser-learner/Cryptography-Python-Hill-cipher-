# Hill Cipher – Cryptography Using Python

## Project Overview

This project is part of my learning in cryptography, where I explored how the **Hill Cipher** works using Python and SageMath.

The aim was to understand how mathematical concepts such as matrices, modular arithmetic, and matrix inverses can be used to encrypt and decrypt messages.

## What I Implemented

- Converted letters into numerical values (A = 0 to Z = 25).
- Divided messages into blocks for matrix calculations.
- Used matrix multiplication and modulo 26 for encryption.
- Applied inverse matrices to decrypt ciphertext.
- Created Python functions to process and decrypt messages.
- Tested the functions using different ciphertexts and encryption keys.
- Verified encryption and decryption results.

## Tools 

- Python
- SageMath

## What I Learned

Through this activity, I gained practical experience in applying mathematical concepts to cryptography.

I learned how the Hill Cipher uses matrices to transform plaintext into ciphertext and how inverse matrices are used to recover the original message.

This project also helped me improve my Python programming skills, particularly working with functions, loops, lists, and mathematical operations.

## Key Takeaway

This exercise helped me understand the connection between mathematics, programming, and cryptography. It also strengthened my understanding of classical encryption techniques and their role in learning the fundamentals of cybersecurity.

**Note:** The Hill Cipher is a classical encryption technique used for educational purposes and is not considered secure for modern applications.
